04 · Ports & data types ★
Following the Unreal Blueprint convention — shape encodes structure, color encodes type. Here shape carries a single axis: direction (input socket vs output plug), identical for every data type. Color is allocated per type-family, so the palette scales as new types are added — a new type simply joins its family's hue instead of demanding a brand-new shape.
Shape = direction · only two, ever
Input · socket
A hollow ring on the left edge. Fills with the incoming type's color once wired — {{ connHint }}.
Output · plug
A solid disc on the right edge — always emitting. Its color tells you the type it produces.
Color = type, grouped in families · scales without new shapes

Direct from the GLSL uniform surface: sampler2D → texture, samplerCube → cubemap, int/bool round out the scalars, and mat2–4 form the new Matrix family. One flat color per family — every member shares the exact hue; the port label alone states the precise type. Color signals the family, the label carries the detail, so it stays color-blind safe as the type count grows.

07 · Motion principles
90–150ms
Fast & restrained
The render loop is realtime — UI motion never competes with the canvas. No decorative easing.
cubic-bezier
(.2,.7,.3,1)
One curve
Panels, popovers and toasts share a single ease-out. Consistency over flair.
pulse · glow
Reserved for state
The only ambient animation: record dot, compiling shimmer, active port glow. Motion means something changed.
